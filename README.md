# 🚀 CodeRetain

A modern coding question management and revision platform built using **HTML5, CSS3, and Vanilla JavaScript**.

CodeRetain helps developers organize coding questions, schedule revisions, track learning progress, and improve long-term problem-solving skills through a structured revision workflow.

Designed with a modern glassmorphism interface, progress analytics, and an intuitive user experience to make coding revision more effective.
